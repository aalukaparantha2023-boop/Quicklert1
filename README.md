# Quicklert

Quicklert is a lightweight alert dashboard built as a simple front-end web app. It lets you:

- add high-priority or normal alerts
- write a quick note for each item
- toggle alerts as complete or reopen them
- filter by status and urgency
- keep your list saved in the browser using local storage

## Run locally

You can open `index.html` directly in a browser, or serve the folder locally:

```bash
cd Quicklert1
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Files

- `index.html` – app layout
- `style.css` – dashboard styling
- `app.js` – alert logic and local storage state

## Notes

This is a clean starter app designed to be easy to extend with a backend, database, or team collaboration features later.
